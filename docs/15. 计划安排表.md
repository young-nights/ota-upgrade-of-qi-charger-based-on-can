# Qi 无线充电模块项目计划安排表

> 项目：基于 AT32F426 的 Qi 无线充电模块（CAN 通信 + OTA + 充电管理）
> 规格依据：`6. qi_charger_srs_zh.md`（LIME-QI-PERIPH-SRS-001 v1.1）
> 更新：2026-09-09 V1.1.1

---

## 一、总体架构

```
┌──────────┐    CAN 250kbps    ┌──────────────────────────────┐
│  CCU (0x03)│ ───────────────→ │  Qi 充电模块 (0x0D)           │
│  UDS 客户端 │ ←─────────────── │  ├─ Bootloader (OTA)         │
│           │  0x18DA0D03/0D   │  ├─ APP (UDS + 充电控制)      │
│           │                   │  ├─ QI 芯片 (I2C/SPI)        │
│           │                   │  ├─ SIT1145 (CAN 收发器)     │
│           │                   │  └─ CAN 采样点 75% @250kbps  │
└──────────┘                   └──────────────────────────────┘
                │ Qi 磁场
                ▼
          手机 / Qi 接收端
```

**CAN ID 分配**：

| 用途         | CAN ID         | 方向                           |
| ------------ | -------------- | ------------------------------ |
| UDS 请求     | `0x18DA0D03` | CCU → Qi                      |
| UDS 响应     | `0x18DA030D` | Qi → CCU                      |
| 生命周期广播 | `0x18FF260D` | Qi → 广播（GE=0x26, SA=0x0D） |
| UDS 功能寻址 | `0x18DB33xx` | CCU → Qi（SA 忽略）           |

## 二、充电状态机（SRS §6）

**11 个状态**，需求 ID：`QI-STATE-001` ~ `QI-STATE-019`

```
                          ┌─────────────────┐
                          │   DISABLED (0)   │◄──────── 上电/复位默认
                          └───────┬─────────┘
                    CCU 使能 0x01 │
                          ┌───────▼─────────┐
                  ┌──────►│   STANDBY (1)    │◄────── 接收端移开 / 故障恢复
                  │       └───────┬─────────┘
                  │   Hall+Qi ping│接收端检测+去抖
                  │       ┌───────▼─────────┐
                  │       │DEVICE_DETECTED(2)│
                  │       └───────┬─────────┘
                  │           校验通过
                  │       ┌───────▼─────────┐
                  │       │NEGOTIATING (3)   │──失败重试──→DEVICE_DETECTED
                  │       └───────┬─────────┘──超限──────→FAULT
                  │        协商成功│
                  │       ┌───────▼─────────┐
                  └───────│  CHARGING (4)    │──完成──→CHARGE_COMPLETE
                   移开    └──┬──────┬──────┘
                  ┌──────────┘      │
           ┌──────▼─────────┐  ┌────▼──────────────┐
           │CHARGE_COMPLETE(5)│ │SUSPENDED_THERMAL(6)│
           └────────────────┘  └───────────────────┘
                                ┌───────────────────┐
                                │ SUSPENDED_FOD (7)  │
                                └───────────────────┘
                                ┌───────────────────┐
                                │    FAULT (8)       │
                                └───────────────────┘
                                ┌───────────────────┐
                                │ SERVICE_MODE (9)   │
                                └───────────────────┘
                                ┌───────────────────┐
                                │   LOW_POWER (0x0A) │
                                └───────────────────┘
```
