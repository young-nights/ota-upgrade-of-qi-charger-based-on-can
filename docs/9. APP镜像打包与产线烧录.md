# APP 镜像打包与产线烧录

> **架构**：Boot + App + 备份区（OTA-ARCH-0920）。App 镜像固定链接
> `0x08004100`（Keil IROM1），无槽选择、无重定位。
> **适用**：Keil 编出 App 裸 `.bin` → `pack_image.py` 加 XATO 头 →
> `merge_prod_bin.py` 合并 Boot → 产线烧录；SN 由扫码 + CCU UDS 写入。

## 1. 工具与产物

| 工具 | 作用 | 位置 |
|---|---|---|
| `pack_image.py` | App 裸 bin → XATO 签名镜像，按版本自动命名输出 `app bin/app_image_v{x}_{y}_{z}.bin` | `python_tools/1.packaging script/` |
| `verify_image.py` | 校验 XATO 镜像（magic/length/CRC/Reset 窗口/ECDSA） | 同上 |
| `merge_prod_bin.py` | Bootloader + App 镜像（自动取 `app bin/` 最新 `app_image*.bin`）→ `burn bin/prod_image.bin` | 同上 |

产线烧录内容 = **Bootloader + App 区镜像**（合并单文件）。备份区出厂为空（0xFF），留给 CAN OTA；metadata 出厂为空，BOOT 首启 defaults 自愈。

## 2. 烧录布局（merge_prod_bin.py 输出）

```
0x08000000  Bootloader 16KB 补 0xFF（qi_wireless_bootloader/mdk_project/Objects/bootloader.bin）
0x08004000  App 区 48KB：XATO 头 256B + 固件（整镜像 ≤ 0xC000）
0x08010000  备份区 48KB：出厂不烧（0xFF），OTA 暂存区
0x0801C000  Metadata：出厂不烧（BOOT 首启 defaults 自愈）
```

## 3. 构建与打包步骤

1. Keil 打开 `qi_wireless_code_app/mdk_project/qi_wireless_code_app.uvprojx`
   （Target IROM1=`0x08004100`，Size=`0xBF00`）→ Rebuild →
   `mdk_project/Objects/qi_wireless_code_app.bin`。
2. 在 `python_tools/1.packaging script/` 下执行 `python pack_image.py`
   （默认输入即上述 bin；`--bin` 改输入，默认私钥 `docs/keys/private.pem`
   可用 `--key` 改，`--out-name` 覆盖自动命名）→ 输出
   `../app bin/app_image_v{x}_{y}_{z}.bin`。脚本自动校验：XATO magic 与
   length、整镜像 ≤ 0xC000、Reset 向量须落 App 窗口 `[0x08004100,0x08010000)`、
   头 CRC 与 payload 一致，签名后 `_selfcheck_image` 用 `docs/keys/public.pem`
   独立仿射验签，任一失败不出包。
3. `python verify_image.py "../app bin/app_image_v1_1_1.bin" --key ../../docs/keys/public.pem`
   （文件名按实际产物）→ RESULT: PASS 后方可交付。
4. 产线：`python merge_prod_bin.py`（boot 默认取
   `qi_wireless_bootloader/mdk_project/Objects/bootloader.bin`，app 自动取
   `app bin/` 最新 `app_image*.bin`；`--hex` 另出 HEX，非 XATO 镜像默认拒绝
   合并）→ `../burn bin/prod_image.bin` → 烧录器基址 `0x08000000`。

## 4. 版本号约定

- 版本唯一真相源 = 固件 `SW_VERSION_STR`（`can_protocol.c`，`QC_JYF_FW_x.y.z`），
  DID `0xF195` 直读；XATO 头 @0x4C 为 16B 保留占位（填 0x00），不含版本。
- `pack_image.py` 自动命名：扫 bin 内 `QC_JYF_FW_x.y.z` → `app_image_v{x}_{y}_{z}.bin`；
  提取失败回落 `app_image.bin`（WARNING）；`--out-name` 指定时忽略自动命名。
- `merge_prod_bin.py` 默认取 `app bin/` 下 mtime 最新的 `app_image*.bin`（`--app` 可指定）。
- OTA 版本闸门（`zcanpro_ext_ota_auto.py`）：`EXPECTED_SW_VERSION` 留空=通用模式
  不闸门、预期版本取镜像内版本串；设置后 bin 版本不符直接拒闪。升级起点
  `BASELINE_SW_VERSION` 核对仅提醒、不拦截。

## 5. OTA 侧衔接

OTA 脚本 `zcanpro_ext_ota_auto.py` 将同一镜像经 UDS 写入**备份区 0x08010000**：

`10 02` + `27` 解锁 → `2E 2010`（下载目标=APP）→ `31` 擦备份区
（0x08010000~0x0801BFFF）→ `22 2114` 核验备份标记 → `34`（地址门禁=
0x08010000）→ `36` → `37` 验签+commit_backup（回 `0x77` 后 **APP 自动
复位**：SHUTDOWN 广播→`NVIC_SystemReset`，无需主机请求，2026-09-23
恢复）→ BOOT 搬运 Backup→App（擦 App 区→复制+回读复核→清标志）→ 跳转
`0x08004100`。复位确认窗口 45s（`confirm_app_after_reset`）后按 DID 组合核验：

| DID | 语义 | 升级成功判据 |
|---|---|---|
| `22 F195` | 运行版本（SW_VERSION_STR 直读） | == 预期版本（硬判据） |
| `22 2113` | 运行槽（单 App 恒 0x00=App 区） | == `0x00`（硬判据） |
| `22 2112` | OTA 状态，现行实现输出 00/01/03/05/06：`05`=Confirmed 搬运成功 | == `0x05`（辅证） |
| `22 2114` | 备份区标记：`02`=待搬运 / `FE`=无 | == `0xFE`（辅证） |
| `22 2115` | 上次启动原因：`03`=OTA 搬运成功 / `04`=搬运失败 | == `0x03`（辅证） |
| `22 2116` | 搬运重试计数 | `0` 为佳；>0 搬运曾失败（辅证） |

与验收相关的 UDS 行为：
- `31 01 21 00` Clear Faults：默认会话即可执行（无需 `10 02`/`27`），正响应
  `71 01 21 00 00`；仅 StartRoutine，其余子功能回 NRC 0x31。
- `11 01` ECUReset：**已删除（2026-09-23）**——设备不再应答 `51 01`、不再
  应答后复位（请求回 NRC serviceNotSupported）；升级完成复位由 `0x37` 收尾
  自动执行，主机侧无 11 01 发送步骤，升级完成信号后直接等待复位重启并按
  上表 DID 组合判定。

## 6. 常见问题

| 现象 | 原因 | 处置 |
|---|---|---|
| pack 报 Reset 不在 App 窗口 | Keil IROM1 不是 0x08004100 | 改 Target IROM1 后 Rebuild 再打包 |
| pack 报"skip (not found)" | Keil 输出名/路径不符 | 确认 `mdk_project/Objects/qi_wireless_code_app.bin` 存在或 `--bin` 指定 |
| `0x37` 回 NRC 0x72 | program_flush/字节数/commit_backup/验签失败（`OTA_VERIFY_ENFORCE=1` 严格校验，2026-10-02 起；2026-09-23~10-01 测试期曾置 0 强制放行） | 检查传输完整性后重新打包重传；验签失败请确认镜像由 `docs/keys/private.pem` 签名 |
| OTA 后版本未变 | 备份区校验失败或搬运未完成 | 按 §5 DID 组合定位（`2115`/`2116`/`2112`），并抓 M1~M4 诊断帧看 M2 搬运结果与 M3 验签关卡 |
| 合并 bin 报 App 过大 | 整镜像超 48KB (0xC000) | 精简固件或检查打包输入是否为错文件 |
