# Flash 空间分配 — QI Wireless Bootloader

> **MCU**: AT32F426 (Cortex-M4F, 128KB Flash, 20KB SRAM)
> **Flash 基地址**: 0x08000000 | **总大小**: 128KB (0x08000000~0x0801FFFF)

---

## 一、Flash 布局总览

| 区域 | 起始 | 结束 | 大小 | 扇区(4KB) | 说明 |
|---|---|---|---|---|---|
| Bootloader | `0x08000000` | `0x08002FFF` | 12KB (0x3000) | 0~2 | 引导程序：metadata 读取、备份区搬运、验签、跳转 |
| App 区（Application） | `0x08003000` | `0x0800FFFF` | 52KB (0xD000) | 3~15 | 应用固件运行区；XATO 头 @0x08003000，入口 0x08003100 |
| Backup（备份区） | `0x08010000` | `0x0801CFFF` | 52KB (0xD000) | 16~28 | OTA 暂存区：主机写入待升级固件，BOOT 校验后搬运至 App 区 |
| Metadata Primary | `0x0801D000` | `0x0801D7FF` | 2KB | 29 (低半) | OTA 元数据主副本 |
| Metadata Backup | `0x0801D800` | `0x0801DFFF` | 2KB | 29 (高半) | OTA 元数据备副本 |
| Device Info | `0x0801E000` | `0x0801EFFF` | 4KB | 30 | SN、ECDSA 公钥、Qi 芯片版本缓存等设备标识；OTA 擦写永不触碰 |
| NVM Config | `0x0801F000` | `0x0801FFFF` | 4KB | 31 | APP NVM 配置区 |

```
0x08000000 ┌──────────────────────────────┐
           │     Bootloader (12KB)        │
0x08003000 ├──────────────────────────────┤
           │     App 区 (52KB)            │
0x08010000 ├──────────────────────────────┤
           │     备份区 (52KB)            │
0x0801D000 ├──────────────────────────────┤
           │  Metadata Primary (2KB)      │
0x0801D800 ├──────────────────────────────┤
           │  Metadata Backup  (2KB)      │
0x0801E000 ├──────────────────────────────┤
           │  Device Info (4KB)           │
0x0801F000 ├──────────────────────────────┤
           │  NVM Config (4KB)            │
0x0801FFFF └──────────────────────────────┘
```

各区边界相接零重叠。扇区 N 起址 = 0x08000000 + N×0x1000。

### 空间优化说明（v2 布局）

| 区域 | 旧布局 | 新布局 | 变化 |
|---|---|---|---|
| Bootloader | 16KB | 12KB | -4KB |
| App 区 | 48KB | 52KB | +4KB |
| Backup | 48KB | 52KB | +4KB |
| NVM Config | 8KB | 4KB | -4KB |
| Metadata / Device Info | 不变 | 不变 | — |

Boot 和 NVM 各压缩 4KB，共 8KB 平分给 App 与 Backup。

**约束**：
- Bootloader 代码须压进 12KB（含中断向量表 + metadata 读写 + 搬运 + ECDSA 验签 + 跳转）
- NVM 配置须控制在 4KB 以内

## 二、Keil 地址与大小设置

| 工程 | Keil 设置项 | 起始地址 | 大小 |
|---|---|---|---|
| qi_wireless_bootloader | IROM | 0x08000000 | 0x3000 |
| qi_wireless_code_app | IROM1 | 0x08003100 | 0xCF00 |

App 区 0x08003000~0x0800FFFF 共 52KB（0xD000），前 256B 留给 XATO 包头，代码从 0x08003100 开始，所以 IROM1 size = 0xD000 - 0x100 = 0xCF00。

烧录时 bootloader 和 app 合并烧录（merge_prod_bin.py），基址 0x08000000。

## 三、ota_metadata_t 数据结构

| 偏移 | 字段 | 大小 | 说明 |
|---|---|---|---|
| 0x00 | magic | 4B | 0x4F54414D "MATO" |
| 0x04 | version | 4B | 4（v3 及更早拒绝后默认重建） |
| 0x08 | backup_valid | 1B | 备份区待搬运标志 |
| 0x09 | copy_fail_step | 1B | 上次搬运失败关卡 |
| 0x0A | last_boot_reason | 1B | 00=POR 01=SW 02=WDG 03=OTA 04=copy失败 |
| 0x0B | reserved0 | 1B | 对齐 |
| 0x0C | backup_crc32 | 4B | 备份区 payload CRC（搬运前比对值） |
| 0x10 | copy_retry_count | 4B | 搬运失败次数 |
| 0x14 | ota_state | 1B | 00=idle 01=downloading |
| 0x15 | reserved[3] | 3B | — |
| 0x18 | crc32 | 4B | 以上字段 CRC32 |

合计 0x1C = 28B。

定义源：boot_metadata.h 与 ota_trigger.h 逐字节同构。

## 四、XATO 镜像头结构

| 偏移 | 字段 | 大小 | 说明 |
|---|---|---|---|
| 0x00 | magic | 4B | 0x4F544158 "XATO" |
| 0x04 | image_length | 4B | 头之后固件字节数 |
| 0x08 | crc32 | 4B | payload CRC32 |
| 0x0C | signature[64] | 64B | ECDSA P-256 R\|\|S |
| 0x4C | hdr_reserved_ver[16] | 16B | 保留占位，打包填 0x00 |
| 0x5C | build_timestamp | 4B | Unix 时间戳 |
| 0x60 | reserved[160] | 160B | 补齐 256B |

版本号唯一真相源 = 固件 SW_VERSION_STR（can_protocol.c），DID 0xF195 直读。
