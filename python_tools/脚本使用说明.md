# 脚本使用说明

> 命令均在仓库根目录下执行。
> zcanpro/ 与 wsl/ 目录已于 2026-10-28 删除（脚本废弃，主机侧由
> QiChargerStationTool / ProductionStationTool 取代）。

## 目录结构

```
python_tools/
├── packaging/          # 打包/签名/校验工具（不依赖 CAN 硬件）
├── app bin/            # XATO 签名镜像输出目录（pack_image.py 产物，不入库）
├── burn bin/           # Boot+App 合并烧录产物（merge_prod_bin.py 输出，不入库）
├── iap bin/            # Qi 芯片 IAP 固件目录（QI_IAP_Ver_x_y_z.BIN）
└── 脚本使用说明.md      # 本文件
```

---

## packaging/ — 打包工具

| 脚本 | 用途 | 命令 |
|------|------|------|
| `pack_image.py` | 裸 bin → XATO 签名镜像（自动命名 `app_image_v{x}_{y}_{z}.bin`） | `python python_tools/packaging/pack_image.py` |
| `verify_image.py` | 校验 XATO 镜像（Magic/CRC/Reset 向量/签名） | `python python_tools/packaging/verify_image.py "python_tools/app bin/app_image_v1_2_1.bin"` |
| `merge_prod_bin.py` | Boot + App 合并为产线烧录 bin（输出 `burn bin/prod_image_vX_Y_Z.bin`） | `python python_tools/packaging/merge_prod_bin.py` |
| `sign_seed.py` | SA seed 签名（27 03 分片 + 27 02 帧） | `python python_tools/packaging/sign_seed.py <seed_hex>` |

---

## 关键参数

| 脚本 | 参数 | 说明 |
|------|------|------|
| `pack_image.py` | `--bin` | 默认 Keil 输出 `qi_wireless_code_app/mdk_project/Objects/qi_wireless_code_app.bin` |
| `pack_image.py` | `--key` | 默认 `docs/keys/private.pem` |
| `pack_image.py` | `--out-name` | 默认按 bin 内版本号命名 `app_image_vX_Y_Z.bin` |
| `verify_image.py` | `--key` | 默认 `docs/keys/private.pem` |
| `merge_prod_bin.py` | `--boot` | 默认 `qi_wireless_bootloader/mdk_project/Objects/bootloader.bin` |
| `merge_prod_bin.py` | `--app` | 默认自动选 `app bin/` 最新 `app_image*.bin` |
| `merge_prod_bin.py` | `--out` / `--hex` / `--force` | 默认输出 `burn bin/prod_image_vX_Y_Z.bin`；`--hex` 附带生成 Intel HEX；`--force` 跳过 XATO Magic 校验 |
| `sign_seed.py` | `seed` / `--key` | 64 hex 字符 seed（67 01 应答）；key 默认 `docs/keys/private.pem` |
