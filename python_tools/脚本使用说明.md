# 脚本使用说明

> 命令均在仓库根目录下执行。

## 目录结构

```
python_tools/
├── packaging/          # 打包/签名/校验工具（不依赖 CAN 硬件）
├── zcanpro/            # ZCANPRO 扩展脚本（Windows ZCANPRO 宿主运行）
│   ├── non-qi/         # OTA、Boot 诊断、SN、SA、版本、充电控制
│   └── qi/             # Qi 芯片 IAP、版本、状态、功率、UART 桥
├── wsl/                # WSL2 独立脚本（ZQWL 串口 CAN 适配器）
├── app bin/            # 打包产物输出目录
├── iap bin/            # Qi 芯片 IAP 固件目录
└── 脚本使用说明.md      # 本文件
```

---

## packaging/ — 打包工具

| 脚本 | 用途 | 命令 |
|------|------|------|
| `pack_image.py` | 裸 bin → XATO 签名镜像（自动命名 `app_image_v{x}_{y}_{z}.bin`） | `python python_tools/packaging/pack_image.py` |
| `verify_image.py` | 校验 XATO 镜像（Magic/CRC/Reset 向量/签名） | `python python_tools/packaging/verify_image.py "app bin/app_image.bin"` |
| `merge_prod_bin.py` | Boot + App 合并为产线烧录 bin | `python python_tools/packaging/merge_prod_bin.py` |
| `sign_seed.py` | SA seed 签名（27 03 分片 + 27 02 帧） | `python python_tools/packaging/sign_seed.py <seed_hex>` |

---

## zcanpro/ — ZCANPRO 扩展脚本

ZCANPRO → 高级功能 → 扩展脚本 → 打开对应 `.py` 文件 → 运行。

### non-qi/（OTA、诊断、SN、充电控制）

| 脚本 | 用途 |
|------|------|
| `zcanpro_ext_ota_auto.py` | OTA 升级主脚本（擦 Backup→下载→验签→自复位→版本核验） |
| `zcanpro_boot_diag_capture.py` | Boot 诊断抓帧 M1~M4（上电窗口 30s） |
| `zcanpro_ota_stress_test.py` | OTA 压力测试循环（逐版本 patch 递增） |
| `zcanpro_read_app_version.py` | 读 APP 版本 DID 0xF195/0xF180/0xF193 |
| `zcanpro_sn_read.py` | 读 SN（22 F18C，默认会话即可） |
| `zcanpro_sn_write.py` | 写 SN（2E F18C，需编程会话+解锁） |
| `zcanpro_charge_start.py` | 启动 Qi 无线充电（扩展会话+解锁+使能） |
| `zcanpro_charge_stop.py` | 停止充电（写 0x2101=0x00） |
| `zcanpro_sa_lockout_test.py` | SA 锁定恢复测试（故意 key 错验证 lockout） |

### qi/（Qi 芯片 IAP、状态、UART）

| 脚本 | 用途 |
|------|------|
| `zcanpro_qi_iap_log1.py` | Qi 芯片 IAP 升级（log1.BIN） |
| `zcanpro_qi_iap_log2.py` | Qi 芯片 IAP 升级（log2.BIN） |
| `zcanpro_qi_read_status.py` | 读 Qi IAP 状态（DID 0x2132，8 字节） |
| `zcanpro_qi_read_version.py` | 读 Qi 芯片版本（DID 0x2133） |
| `zcanpro_qi_set_power.py` | 设置充电功率（DID 0x210D，500/1000/1500 mW） |
| `zcanpro_qi_uart_bridge.py` | Qi UART 抓取/透传桥（0x2140 读 + 0x2141 写） |

## wsl/ — WSL2 独立脚本（ZQWL 串口 CAN）

硬件：ZQWL-CANFD，VID `3562:0101`，attach 后 `/dev/ttyACM0`。步骤见 `AGENTS.md`「WSL2 串口 CAN 监听」。

| 脚本 | 用途 | 命令 |
|------|------|------|
| `zqwl_can_listen.py` | CAN 收包 + Boot M1~M4 监听 | `python3 python_tools/wsl/zqwl_can_listen.py --port /dev/ttyACM0` |
| `zqwl_can_send.py` | 单帧发送 + 窗口抓包（ISO-TP 自动回 FC） | `python3 python_tools/wsl/zqwl_can_send.py --id 18DA0D03 --data "03 22 F1 95 CC CC CC CC" --wait 2` |
| `zqwl_ota_run.py` | WSL2 OTA runner（shim 注入 + 完整 OTA） | `python3 python_tools/wsl/zqwl_ota_run.py --smoke-read` |
| `zqwl_qi_iap_run.py` | WSL2 Qi 数据抓取 / IAP 升级 runner | `python3 python_tools/wsl/zqwl_qi_iap_run.py --sniff` / `--read` / `--iap log1` |
| `zcanpro_shim_zqwl.py` | zcanpro 兼容层（被其他脚本 import，不直接运行） | — |
| `tc0103_tp_keepalive.py` | TC-0103 TesterPresent 保活下载测试 | `python3 python_tools/wsl/tc0103_tp_keepalive.py` |
| `tc0104_response_pending.py` | TC-0104 NRC 0x78 时序观测 | `python3 python_tools/wsl/tc0104_response_pending.py` |
| `tc0105_sn_preserve.py` | TC-0105 SN 保留验证 | `python3 python_tools/wsl/tc0105_sn_preserve.py` |

## 关键参数

| 脚本 | 参数 | 说明 |
|------|------|------|
| `pack_image.py` | `--bin` | 默认 `qi_wireless_code_app/mdk_project/Objects/qi_wireless_code_app.bin` |
| `pack_image.py` | `--key` | 默认 `docs/keys/private.pem` |
| `merge_prod_bin.py` | `--boot` | 默认 `qi_wireless_bootloader/mdk_project/Objects/bootloader.bin` |
| `merge_prod_bin.py` | `--app` | 默认 `app bin/app_image.bin` |
| `zcanpro_ext_ota_auto.py` | `EXPECTED_SW_VERSION` | 脚本内常量，须与固件 `SW_VERSION_STR` 一致 |
| `zcanpro_sn_write.py` | `SN_CODE` | 脚本内常量 |
| `zcanpro_charge_start.py` | `POWER_LEVEL` | `0x03`=15W |
| `zcanpro_qi_set_power.py` | `POWER_MW` | 可选 500/1000/1500 |
| `zcanpro_boot_diag_capture.py` | `CAPTURE_WINDOW_S` | 默认 30.0 秒 |
