# 脚本使用说明

> 命令均在 `python_tools/` 目录下执行。

## 脚本分类

### ZCANPRO 扩展脚本（导入 ZCANPRO 运行）

ZCANPRO → 高级功能 → 扩展脚本 → 打开对应 `.py` 文件 → 运行。

| 脚本 | 用途 |
|---|---|
| `zcanpro_ext_ota_auto.py` | OTA 升级主脚本 |
| `zcanpro_boot_diag_capture.py` | Boot 诊断抓帧（M1~M4） |
| `zcanpro_ota_stress_test.py` | OTA 压力测试循环（1.1.1~1.1.10） |
| `zcanpro_qi_iap_log1.py` | Qi 芯片 IAP 升级（log1.BIN） |
| `zcanpro_qi_iap_log2.py` | Qi 芯片 IAP 升级（log2.BIN） |
| `zcanpro_read_app_version.py` | 读 APP 版本 DID 0xF195/0xF180/0xF193 |
| `zcanpro_sn_read.py` | 读 SN（22 F18C） |
| `zcanpro_sn_write.py` | 写 SN（2E F18C，需编程会话+解锁） |
| `zcanpro_charge_start.py` | 启动 Qi 无线充电 |
| `zcanpro_charge_stop.py` | 停止充电 |
| `zcanpro_qi_set_power.py` | 设置充电功率（0x2E 210D） |
| `zcanpro_qi_read_status.py` | 读 Qi IAP 状态（0x2132） |
| `zcanpro_qi_read_version.py` | 读 Qi 芯片版本（0x2133） |
| `zcanpro_sa_lockout_test.py` | SA 锁定恢复测试 |

## 常用命令

### 打包镜像

```powershell
python "1.packaging script/pack_image.py"
```

可选参数：`--bin <裸bin路径>` `--key <私钥pem>` `--out-name <输出名>`

输出：`app bin/app_image.bin`

### 校验镜像

```powershell
python "1.packaging script/verify_image.py" "app bin/app_image.bin"
python "1.packaging script/verify_image.py" "app bin/app_image.bin" --key ../docs/keys/public.pem
```

输出 `RESULT: PASS` 方可交付。`--key` 可选，省略时跳过 ECDSA 检查。

### 产线合并 bin

```powershell
python "1.packaging script/merge_prod_bin.py"
```

可选参数：`--boot <bootloader路径>` `--app <镜像路径>` `--out <输出路径>` `--hex`

输出：`burn bin/prod_image.bin`，烧录基址 `0x08000000`

### SA seed 签名

```powershell
python "1.packaging script/sign_seed.py" <seed_hex>
```

`seed_hex` = 64 个 hex 字符（32 字节，来自 `67 01` 应答）。

输出 `27 03` 分片帧和 `27 02` 帧的 hex 列表。

## DID 速查

| DID | 含义 |
|---|---|
| `0xF195` | 运行固件版本（OTA 升级判定依据） |
| `0x2113` | 运行区标识（单 App 架构恒 `0x00`） |
| `0x2114` | OTA 目标标记：`0x02`=备份区有镜像，`0xFE`=无 |
| `0x2115` | last_boot_reason：`0x00`=上电 `0x01`=软件复位 `0x02`=看门狗 `0x03`=OTA `0x04`=搬运失败 |
| `0x2116` | 搬运重试计数 |
