# 脚本使用说明

> 命令均在仓库根目录下执行。
> zcanpro/ 与 wsl/ 目录已于 2026-10-28 删除（脚本废弃，主机侧由
> QiChargerStationTool / ProductionStationTool 取代）。

## 目录结构

```
python_tools/
├── packaging/          # 打包/签名/校验工具（不依赖 CAN 硬件）
├── mcu1 app bin/       # MCU1 XATO 签名镜像（pack_image.py 输出）
├── mcu1 burn bin/      # MCU1 Boot+App 合并烧录产物（merge_prod_bin.py 输出）
├── mcu2 iap bin/       # MCU2 Qi 芯片 IAP 升级载荷（QI_IAP_Ver_x_y_z.BIN）
├── mcu2 burn/          # MCU2 整片烧录（MCU2_Burn_Vx_y_z.hex / .bin）
├── release/            # JYF 发布包（Firmware/Release_Note/Test_Report/Checksum）
└── 脚本使用说明.md      # 本文件
```

---

## packaging/ — 打包工具

| 脚本 | 用途 | 命令 |
|------|------|------|
| `pack_image.py` | 裸 bin → XATO 签名镜像（自动命名 `app_image_v{x}_{y}_{z}.bin`） | `python python_tools/packaging/pack_image.py` |
| `verify_image.py` | 校验 XATO 镜像（Magic/CRC/Reset 向量/签名） | `python python_tools/packaging/verify_image.py "python_tools/mcu1 app bin/app_image_v1_2_3.bin"` |
| `merge_prod_bin.py` | Boot + App 合并为产线烧录 bin（输出 `mcu1 burn bin/prod_image_vX_Y_Z.bin`） | `python python_tools/packaging/merge_prod_bin.py` |
| `sign_seed.py` | SA seed 签名（27 03 分片 + 27 02 帧） | `python python_tools/packaging/sign_seed.py <seed_hex>` |

---

## 关键参数

| 脚本 | 参数 | 说明 |
|------|------|------|
| `pack_image.py` | `--bin` | 默认 Keil 输出 `qi_wireless_code_app/mdk_project/Objects/qi_wireless_code_app.bin` |
| `pack_image.py` | `--key` | 默认 `docs/keys/private.pem` |
| `pack_image.py` | `--out-name` | 默认按 bin 内版本号命名，输出到 **`mcu1 app bin/`** |
| `verify_image.py` | `--key` | 默认 `docs/keys/private.pem` |
| `merge_prod_bin.py` | `--boot` | 默认 `qi_wireless_bootloader/mdk_project/Objects/bootloader.bin` |
| `merge_prod_bin.py` | `--app` | 默认自动选 **`mcu1 app bin/`** 最新 `app_image*.bin` |
| `merge_prod_bin.py` | `--out` / `--hex` / `--force` | 默认输出 **`mcu1 burn bin/prod_image_vX_Y_Z.bin`**；`--hex` 附带生成 Intel HEX；`--force` 跳过 XATO Magic 校验 |
| `sign_seed.py` | `seed` / `--key` | 64 hex 字符 seed（67 01 应答）；key 默认 `docs/keys/private.pem` |

## MCU2 烧录（mcu2 burn/）

| 文件 | 用途 |
|------|------|
| `MCU2_Burn_Vx_y_z.hex` | Intel HEX 源（产线/原厂） |
| `MCU2_Burn_Vx_y_z.bin` | 由 hex 转 raw（地址空洞填 `0xFF`），整片烧录用 |

hex→bin：按 Intel HEX 记录展开到 `[min_addr, max_addr]`，空洞填 `0xFF`（Flash 擦除态）。

## 发布包（release/）

按 docs/16 JYF 交付要求组包：

```
python_tools/release/
├── QC_JYF_MCU1_FW_x.y.z_MCU2_FW_a.b.c_Release/
│   ├── Firmware/MCU1/   *.img + *.bin（MD5 后缀）
│   ├── Firmware/MCU2/   *.img（IAP）+ *.bin（整片烧录，如有）
│   ├── Release_Note/    英文 Release Note
│   ├── Test_Report/     英文 Self Test Report
│   └── Checksum/        MD5.txt
└── QC_JYF_MCU1_FW_x.y.z_MCU2_FW_a.b.c_Release.zip
```

源文件映射：

| 发布文件 | 源目录 |
|----------|--------|
| MCU1 `.img` | `mcu1 app bin/app_image_*.bin` |
| MCU1 `.bin` | `mcu1 burn bin/prod_image_*.bin` |
| MCU2 `.img` | `mcu2 iap bin/QI_IAP_Ver_*.BIN` |
| MCU2 `.bin` | `mcu2 burn/MCU2_Burn_*.bin`（由 `.hex` 转换） |
