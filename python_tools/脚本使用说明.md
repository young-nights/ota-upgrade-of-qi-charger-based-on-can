# 脚本使用说明

> 命令均在仓库根目录下执行。

## 目录结构

```
python_tools/
├── packaging/          # 打包/签名/校验工具（不依赖 CAN 硬件）
├── zcanpro/            # ZCANPRO 扩展脚本（Windows ZCANPRO 宿主运行）
│   ├── non-qi/         # OTA、Boot 诊断、SN、SA、版本、充电控制
│   └── qi/             # Qi 芯片 IAP、版本、状态、功率、UART 桥
├── wsl/                # WSL2 独立脚本（ZQWL 串口 CAN 适配器）
├── app bin/            # 打包产物输出目录
├── iap bin/            # Qi 芯片 IAP 固件目录
└── 脚本使用说明.md      # 本文件
```

---

## packaging/ — 打包工具

| 脚本 | 用途 | 命令 |
|------|------|------|
| `pack_image.py` | 裸 bin → XATO 签名镜像（自动命名 `app_image_v{x}_{y}_{z}.bin`） | `python python_tools/packaging/pack_image.py` |
| `verify_image.py` | 校验 XATO 镜像（Magic/CRC/Reset 向量/签名） | `python python_tools/packaging/verify_image.py "app bin/app_image.bin"` |
| `merge_prod_bin.py` | Boot + App 合并为产线烧录 bin | `python python_tools/packaging/merge_prod_bin.py` |
| `sign_seed.py` | SA seed 签名（27 03 分片 + 27 02 帧） | `python python_tools/packaging/sign_seed.py <seed_hex>` |

---

## zcanpro/ — ZCANPRO 扩展脚本

ZCANPRO → 高级功能 → 扩展脚本 → 打开对应 `.py` 文件 → 运行。

### non-qi/

| 脚本 | 用途 |
|------|------|
| `zcanpro_ext_ota_auto.py` | MCU1 OTA 升级 |
| `zcanpro_boot_diag_capture.py` | Boot 诊断抓帧 |
| `zcanpro_ota_stress_test.py` | OTA 压力测试循环 |
| `zcanpro_read_app_version.py` | 读 APP 版本 |
| `zcanpro_sn_read.py` | 读 SN |
| `zcanpro_sn_write.py` | 写 SN |
| `zcanpro_charge_start.py` | 启动充电 |
| `zcanpro_charge_stop.py` | 停止充电 |
| `zcanpro_sa_lockout_test.py` | SA 锁定测试 |

### qi/

| 脚本 | 用途 |
|------|------|
| `zcanpro_qi_iap.py` | Qi 芯片 IAP 升级 |
| `zcanpro_qi_read_status.py` | Qi 状态查询（IAP/充电/传感器） |
| `zcanpro_qi_read_version.py` | 读 Qi 芯片版本 |
| `zcanpro_qi_set_power.py` | 设置充电功率 |
| `zcanpro_qi_uart_bridge.py` | Qi UART 透传桥 |

## wsl/ — WSL2 独立脚本（ZQWL 串口 CAN）

硬件：ZQWL-CANFD，VID `3562:0101`，attach 后 `/dev/ttyACM0`。步骤见 `AGENTS.md`「WSL2 串口 CAN 监听」。

| 脚本 | 用途 | 命令 |
|------|------|------|
| `zqwl_can_listen.py` | CAN 收包 + Boot 诊断监听 | `python3 python_tools/wsl/zqwl_can_listen.py --port /dev/ttyACM0` |
| `zqwl_can_send.py` | 单帧发送 + 窗口抓包 | `python3 python_tools/wsl/zqwl_can_send.py --id 18DA0D03 --data "03 22 F1 95 CC CC CC CC" --wait 2` |
| `zqwl_ota_run.py` | WSL2 OTA runner | `python3 python_tools/wsl/zqwl_ota_run.py --smoke-read` |
| `zcanpro_shim_zqwl.py` | zcanpro 兼容层（被 import，不直接运行） | — |
| `standby_wake_test.py` | 低功耗唤醒测试（充电启停→等→读版本） | `python3 python_tools/wsl/standby_wake_test.py` |
| `tc0103_tp_keepalive.py` | TesterPresent 保活测试 | `python3 python_tools/wsl/tc0103_tp_keepalive.py` |
| `tc0104_response_pending.py` | NRC 0x78 时序观测 | `python3 python_tools/wsl/tc0104_response_pending.py` |
| `tc0105_sn_preserve.py` | SN 保留验证 | `python3 python_tools/wsl/tc0105_sn_preserve.py` |

## 关键参数

| 脚本 | 参数 | 说明 |
|------|------|------|
| `pack_image.py` | `--bin` | 默认 Keil 输出裸 bin |
| `pack_image.py` | `--key` | 默认 `docs/keys/private.pem` |
| `merge_prod_bin.py` | `--boot` | 默认 `bootloader.bin` |
| `merge_prod_bin.py` | `--app` | 默认自动选 `app bin/` 最新 |
| `zcanpro_sn_write.py` | `SN_CODE` | 脚本内常量 |
| `zcanpro_qi_iap.py` | `--firmware` | Qi 固件 bin 路径（默认自动搜索） |
| `zcanpro_charge_start.py` | `POWER_LEVEL` | `0x03`=15W |
| `zcanpro_qi_set_power.py` | `POWER_MW` | 可选 500/1000/1500 |
