# python_tools — 产线与调试工具集

本目录包含 Qi 无线充电模块 CAN-OTA 项目的全部 Python 工具脚本。

**脚本可从任意目录执行**。脚本通过 `__file__` 自动推算仓库根路径，固件/密钥等默认路径不受 `cd` 位置影响。

> ⚠️ 注意：命令行传入的路径参数（如 `--bin`、`--out`）是相对于**当前工作目录**的。如果不在仓库根执行，需要用绝对路径或相对于当前位置的路径。

---

## 脚本总览

| 脚本                         | 功能                                                                         | 典型场景              |
| ---------------------------- | ---------------------------------------------------------------------------- | --------------------- |
| `pack_image.py`            | 裸 bin → 签名 .ota.bin（XATO 头 + CRC32 + ECDSA P-256），输出到`app bin/` | 打包签名              |
| `zcanpro_ext_ota_slotA.py` | ZCANPRO 扩展脚本，指定升级 Slot A（自动打包）                                | 开发调试 OTA Slot A   |
| `zcanpro_ext_ota_slotB.py` | ZCANPRO 扩展脚本，指定升级 Slot B（自动打包）                                | 开发调试 OTA Slot B   |
| `zcanpro_ext_ota_auto.py`  | ZCANPRO 扩展脚本，自动识别 A/B 槽升级                                        | 开发调试 OTA 自动识别 |
| `merge_prod_bin.py`        | Bootloader + APP 合并为单一产线镜像                                          | 产线烧录前打包        |
| `verify_image.py`          | XATO 镜像完整性 + 签名校验                                                   | 打包后自检 / 产线抽检 |
| `sign_seed.py`             | SecurityAccess seed 签名生成 + CAN 帧输出                                    | 手动测试 0x27 解锁    |

## 1. pack_image.py — 镜像打包签名

把 Keil 裸 APP `.bin` 打成带 256 字节 XATO 头的 `.ota.bin`，含 CRC32 + ECDSA P-256 签名。不需要 ZCANPRO 环境。

### 用法

```bash
# 方式一：从仓库根执行（路径参数用相对路径）
cd I:\GitHub-young-nights\ota-upgrade-of-qi-charger-based-on-can
python python_tools/pack_image.py

# 方式二：从 python_tools 目录执行
cd I:\GitHub-young-nights\ota-upgrade-of-qi-charger-based-on-can\python_tools
python pack_image.py

# 显式指定 Slot A 固件
python python_tools/pack_image.py \
  --bin qi_wireless_code_slotA/mdk_project/Objects/qi_wireless.bin \
  --version 1.0.0

# 显式指定 Slot B 固件
python python_tools/pack_image.py \
  --bin qi_wireless_code_slotB/mdk_project/Objects/qi_wireless.bin \
  --version 1.0.0
```

### 参数

| 参数          | 默认值                                         | 说明                           |
| ------------- | ---------------------------------------------- | ------------------------------ |
| `--bin`     | `qi_wireless_code_slotA/.../qi_wireless.bin` | Keil fromelf 产出的裸 APP .bin |
| `--key`     | `docs/keys/private.pem`                      | ECDSA P-256 私钥 PEM           |
| `--out`     | 自动（见下方说明）                             | 输出镜像路径                   |
| `--version` | `1.0.0`                                      | 写入头的版本字符串             |

### 自动输出路径

`--out` 不指定时，脚本根据镜像的 Reset Handler 地址自动判断槽号，输出到：

| 槽     | 输出路径                                |
| ------ | --------------------------------------- |
| Slot A | `python_tools/app bin/app_slot_a.bin` |
| Slot B | `python_tools/app bin/app_slot_b.bin` |

`app bin/` 目录下的 bin 文件供 `zcanpro_ext_ota_auto.py` 自动识别使用。

### 输出布局

```
app_slot_a.bin:
  [0x0000]  XATO Header (256 bytes)
            Magic(4B) + Length(4B) + CRC32(4B) + Signature(64B) + Version(16B) + Timestamp(4B) + Padding
  [0x0100]  Firmware payload (裸 bin 原始数据)
```

产线烧录地址：**`0x08007000`**（含 256 字节头）。Bootloader 烧到 `0x08000000`。

## 2. OTA 脚本（ZCANPRO 扩展脚本）

三个版本的 OTA 脚本，在 ZCANPRO 里一键完成 MCU CAN-UDS OTA，不用手动点 UDS、也不用自己组 ISO-TP。

> **Python**: ZCANPRO 要求 **Python 3.8 32 位**
> **入口**: ZCANPRO → 高级功能 → 扩展脚本 → 打开对应文件
> **总线**: Classical CAN 2.0B，250 kbps，29-bit 扩展帧

### 2.1 三版脚本对比

| 脚本                         | 用途            | 固件来源                                                   | 适用场景                                  |
| ---------------------------- | --------------- | ---------------------------------------------------------- | ----------------------------------------- |
| `zcanpro_ext_ota_slotA.py` | 指定升级 Slot A | `qi_wireless_code_slotA/.../qi_wireless.bin`（自动打包） | 当前 APP 在 Slot B，升级 Slot A           |
| `zcanpro_ext_ota_slotB.py` | 指定升级 Slot B | `qi_wireless_code_slotB/.../qi_wireless.bin`（自动打包） | 当前 APP 在 Slot A，升级 Slot B（最常见） |
| `zcanpro_ext_ota_auto.py`  | 自动识别 A/B 槽 | 扫描`app bin/` 目录下已打包的 bin                        | 不确定当前槽，自动选择                    |

### 2.2 slotA / slotB 脚本使用

```bash
# 在 ZCANPRO 中打开对应脚本即可
# 脚本会自动读取 Keil 输出的 qi_wireless.bin，现场打包后升级
```

### 2.3 auto 脚本使用

auto 脚本扫描 `app bin/` 目录，通过 Reset Handler 地址自动识别 Slot A/B。

使用前需要先用 `pack_image.py` 打包：

```bash
# 先打包到 app bin/
python python_tools/pack_image.py --bin qi_wireless_code_slotA/mdk_project/Objects/qi_wireless.bin
python python_tools/pack_image.py --bin qi_wireless_code_slotB/mdk_project/Objects/qi_wireless.bin

# 然后在 ZCANPRO 中运行 zcanpro_ext_ota_auto.py
# 脚本自动从 app bin/ 找匹配的固件升级
```

### 2.4 OTA 流程

1. （可选）让正在跑的 APP 进 Bootloader（`RESET_APP_TO_BOOT = True`）
2. Programming Session + ECDSA P-256 解锁（`27 01` → `27 03` 分 16 帧送签名 → `27 02` 验签）
3. 擦除非活跃槽，读 DID `0x2114` 核对目标槽
4. 分块下发镜像（`0x34` + `0x36`），`TransferExit` 验签
5. 复位后确认已在 APP

### 2.5 脚本顶部配置

```python
RESET_APP_TO_BOOT = True       # APP 在跑则先复位进 Boot
DOWNLOAD_ADDR = 0x08007000     # 兜底；实际用 DID 0x2114 的槽基址
TRANSFER_BLOCK_DATA = 128      # 每块数据字节，1..254
```

### 2.6 Slot 对照

| 槽 | Keil Target IROM1 Start | IROM1 Size | 适用场景                       |
| -- | ----------------------- | ---------- | ------------------------------ |
| A  | `0x08007100`          | `0xA700` | 空片首次下载，或当前活跃槽为 B |
| B  | `0x08011900`          | `0xA700` | 当前 APP 跑在 Slot A（最常见） |

### 2.7 CAN 诊断 ID

| 方向        | CAN ID         |
| ----------- | -------------- |
| 主机 → MCU | `0x18DA0D03` |
| MCU → 主机 | `0x18DA030D` |

### 2.8 正常日志顺序

```text
======== Qi CAN-UDS OTA ========
固件 .../qi_wireless.bin
私钥 .../private.pem
固件无头，现场打包 xxxxx 字节
打包完成 crc=0xXXXXXXXX version=1.0.0
镜像链接 Slot X, 总长 xxxxx
UDS 就绪 0x18DA0D03 / 0x18DA030D 扩展帧
---- APP 进 Boot ----          （仅 RESET_APP_TO_BOOT=True）
---- Programming ----          0x10 0x02
---- SecurityAccess ----       0x27 0x01 seed → 0x27 03 分片签名 → 0x27 02 验签
---- DID 0x2010 APP ----       0x2E 20 10 01
---- 擦除 ----                 0x31 01 FF 00
擦除目标 Slot X (DID 0x2114=x)
---- RequestDownload ----      0x34
---- TransferData ----         0x36，打印进度
---- TransferExit ----         0x37
---- Reset ----                0x11
======== OTA 成功 ========
```

### 2.9 失败对照

| 日志/现象                      | 原因                                 | 处理                                            |
| ------------------------------ | ------------------------------------ | ----------------------------------------------- |
| 请先打开 CAN 通道              | 设备未启动                           | 先打开 250kbps 扩展帧通道                       |
| 找不到固件 / 找不到私钥        | 路径错误                             | 检查 Keil 编译输出路径                          |
| UDS 无应答                     | 波特率/帧类型错、接线                | 250k 扩展帧                                     |
| NRC`0x35`                    | 私钥和 MCU 公钥不匹配                | 换密钥或重编 Bootloader                         |
| NRC`0x72`                    | CRC/签名失败，或镜像链接地址不在本槽 | 用对应槽的 bin                                  |
| Reset Handler 不在 Slot A/B 内 | Keil IROM1 地址设错                  | Slot A =`0x08007100`，Slot B = `0x08011900` |
| 复位后无 UDS                   | 跳转失败或 APP CAN 未起来            | 检查 Bootloader 版本和镜像完整性                |

## 3. merge_prod_bin.py — 产线镜像合并

将 Bootloader 与 APP 合并为单一产线镜像，用于一次性烧录。

### 用法

```bash
# 方式一：从仓库根执行
cd I:\GitHub-young-nights\ota-upgrade-of-qi-charger-based-on-can
python python_tools/merge_prod_bin.py

# 方式二：从 python_tools 目录执行
cd I:\GitHub-young-nights\ota-upgrade-of-qi-charger-based-on-can\python_tools
python merge_prod_bin.py

# 显式指定 + 同时生成 HEX（从仓库根执行时）
python python_tools/merge_prod_bin.py --hex

# 自定义路径
python python_tools/merge_prod_bin.py \
  --boot qi_wireless_bootloader/mdk_project/Objects/bootloader.bin \
  --app  python_tools/app_bin/app_slot_a.bin \
  --out  python_tools/prod_image.bin
```

### 参数

| 参数       | 默认值                                        | 说明                  |
| ---------- | --------------------------------------------- | --------------------- |
| `--boot` | `qi_wireless_bootloader/.../bootloader.bin` | Bootloader 二进制     |
| `--app`  | `python_tools/app_bin/app_slot_a.bin`       | 已签名 APP 镜像       |
| `--out`  | `python_tools/prod_image.bin`               | 合并输出路径          |
| `--hex`  | —                                            | 同时生成`.hex` 文件 |

### 输出布局

```
prod_image.bin:
  0x0000  Bootloader  28KB (不足补 0xFF)
  0x7000  Slot A      (256B XATO 头 + 固件)
```

烧录地址：**`0x08000000`**（从 Flash 起始烧）。

### 约束

| 检查项                 | 限制                 |
| ---------------------- | -------------------- |
| Bootloader 大小        | ≤ 28KB (`0x7000`) |
| APP 镜像总长（含头）   | ≤ 42KB (`0xA800`) |
| APP 镜像必须含 XATO 头 | 脚本会警告但不阻断   |

## 4. verify_image.py — 镜像离线校验

一键验证 XATO 镜像的 6 项完整性检查，与 Bootloader `boot_verify_image()` 逻辑一致。

### 用法

```bash
# 从仓库根执行
python python_tools/verify_image.py python_tools/app_bin/app_slot_a.bin

# 指定公钥
python python_tools/verify_image.py <image_path> --key docs/keys/public.pem
```

### 检查项

| # | 检查            | 说明                                   | 对应 MCU 失败码            |
| - | --------------- | -------------------------------------- | -------------------------- |
| 1 | Magic           | 首 4 字节必须为`0x4F544158` ("XATO") | `g_verify_fail_step = 1` |
| 2 | Image Length    | 不能为 0，不能超出固件实际大小         | `g_verify_fail_step = 2` |
| 3 | CRC32           | IEEE 802.3 CRC 覆盖裸固件（不含头）    | `g_verify_fail_step = 3` |
| 4 | Version         | 读取头中版本字符串（信息性）           | —                         |
| 5 | Build Timestamp | 读取打包时间戳（信息性）               | —                         |
| 6 | ECDSA P-256     | SHA-256(固件) + OpenSSL 验签           | `g_verify_fail_step = 6` |

### 退出码

| 退出码 | 含义                 |
| ------ | -------------------- |
| 0      | 全部通过             |
| 1      | 有检查项失败         |
| 2      | 文件不存在或格式错误 |

### 依赖

- Python 3.6+
- OpenSSL CLI（签名验证需要，必须在 PATH 中）

## 5. sign_seed.py — SecurityAccess 签名生成

手动测试 UDS 0x27 SecurityAccess 时，收到 MCU 返回的 4 字节 seed 后，一键生成 ECDSA P-256 签名及可直接粘贴的 CAN 帧数据。

### 用法

```bash
# 从仓库根执行
python python_tools/sign_seed.py A1B2C3D4

# 指定私钥
python python_tools/sign_seed.py A1B2C3D4 --key docs/keys/private.pem
```

### 参数

| 参数      | 默认值                    | 说明                             |
| --------- | ------------------------- | -------------------------------- |
| `seed`  | （必填）                  | MCU 返回的 4 字节 seed，十六进制 |
| `--key` | `docs/keys/private.pem` | ECDSA P-256 私钥 PEM             |

### 输出内容

- ECDSA 签名（64 字节 P1363 格式）
- Method A: `27 02` ISO-TP 多帧（10 帧）
- Method B: `27 03` 分块传输 + `27 02` 触发校验（12 帧）

### MCU 响应对照

| MCU 回复     | 含义                             |
| ------------ | -------------------------------- |
| `67 02`    | 解锁成功                         |
| `7F 27 35` | Invalid Key（签名校验失败）      |
| `7F 27 36` | 超过失败次数，锁定 30 秒         |
| `7F 27 78` | Response Pending（验证中，等待） |

### 依赖

- Python 3.6+
- OpenSSL CLI 或 `pip install ecdsa`

```
Keil Rebuild → fromelf → qi_wireless.bin (裸 bin)
                            │
              python_tools/pack_image.py
                            │
                  app bin/app_slot_a.bin (XATO 头 + 签名)
                            │
                ┌───────────┴───────────┐
                │                       │
    python_tools/verify_image.py   python_tools/merge_prod_bin.py
    (校验 6 项全部 PASS)              │
                                  prod_image.bin
                                        │
                              J-Link / AT32 ISP 烧录 0x08000000
```

### 7.2 开发调试 OTA

```
# Slot A → Slot B 升级（最常见）
# 1. Keil 编译 Slot B 固件（IROM1 = 0x08011900）
# 2. 在 ZCANPRO 中运行 zcanpro_ext_ota_slotB.py
# 3. 脚本自动打包 qi_wireless_code_slotB/.../qi_wireless.bin 并升级

# 或者用 auto 脚本
```

## 8. 常见问题

| 问题                                     | 原因                                       | 解决                                                       |
| ---------------------------------------- | ------------------------------------------ | ---------------------------------------------------------- |
| `pack_image.py` 报找不到固件/私钥      | 默认路径指向`qi_wireless_code_slotA/...` | 检查 Keil 编译输出路径或用`--bin`/`--key` 指定         |
| `verify_image.py` 报 Magic 错误        | 输入文件不是 XATO 格式                     | 只验证`app bin/` 下的 bin，不要验证裸 bin                |
| `verify_image.py` 报签名全零           | 镜像未签名                                 | 用`pack_image.py` 重新打包                               |
| `merge_prod_bin.py` 报 Bootloader 超大 | bootloader.bin > 28KB                      | 精简 Bootloader 代码                                       |
| `merge_prod_bin.py` 报 APP 超大        | 打包后 > 42KB                              | 减小 APP 或调整 IROM1 Size                                 |
| `sign_seed.py` 报签名失败              | openssl 不在 PATH 或私钥不存在             | 安装 OpenSSL / 检查`docs/keys/private.pem`               |
| OTA 脚本报找不到 CAN 通道                | ZCANPRO 未打开通道                         | 先打开 250kbps 扩展帧通道                                  |
| OTA 脚本报 NRC`0x35`                   | 私钥与 MCU 公钥不匹配                      | 换密钥或重编 Bootloader                                    |
| OTA 脚本报 NRC`0x72`                   | 镜像链接 Slot 与目标槽不符                 | 用对应 Slot 的 bin 重新打包                                |
| OTA 脚本报 Reset Handler 不在 Slot 内    | Keil IROM1 地址设错                        | Slot A =`0x08007100`，Slot B = `0x08011900`            |
| `pack_image.py` 导入报错               | `zcanpro_ext_ota.py` 已重命名            | 确保`zcanpro_ext_ota_slotA.py` 存在（pack_image 依赖它） |
